## 已登记差异

1. 本地后端环境数据没有 `updatedAt/updatedBy` 时，Vue 显示“暂无更新时间”，Make 示例显示具体操作者和时间；这是数据来源差异。
2. 本地环境列表与 Make 示例的环境数量、名称、Base URL、请求头和变量集数量不同；这是业务数据差异，不应伪造示例值修复。
3. 当前本地 API 页在真实数据为空时显示 Base URL 空态提示，Make 截图使用有 Base URL 的示例；两者结构一致但内容不同。
4. Make 预览会在加载过程中退回登录页，需要重新登录后才能继续验证；已恢复操作，仍保留为预览稳定性风险。
5. 本地变量集数据没有可复现 Make 示例的同名冲突，变量冲突“生效/被覆盖”状态仍缺少真实后端对照。
6. Make 的基础信息标识符说明位于字段标题同行；本地此前渲染在输入框下方，已改为同行 hint。详情内容此前由各 Tab 面板分别承担滚动，已改为单一 `.figma-env__detail-content` 滚动容器，避免底部操作条遮挡和滚动条位置不一致。

## 结论

`partial-alignment`。Make 退回登录后重新登录即可继续，未构成阻塞；本轮修正了明确的文案、字段 hint 和变量绑定首项标记差异。仍有未验证状态、未完成叠加审查、真实生产保存证据和本地冲突数据不足，因此不能称“完全对齐”。
